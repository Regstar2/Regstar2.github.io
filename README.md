# Regstar GitHub Pages

Personal GitHub Pages site for [Regstar2](https://github.com/Regstar2).

## Site

https://regstar2.github.io/

## Structure

- `index.html` — page content and project cards.
- `styles.css` — responsive layout, typography and theme.
- `script.js` — responsive navigation and skeleton easter egg dialog.
- `app-ads.txt` — existing advertising declaration used by published apps.

The site is intentionally static and does not require a build step.

## Content policy

Only repositories confirmed as `public` in GitHub's repository metadata may appear on the site or in the public profile README. Re-check visibility before each publication and remove project references if a repository becomes private. Never copy data from private issues, pull requests, or branches.

Project stages and release links are checked against each public repository's README and published GitHub Releases. The English and Russian landing pages must stay in sync. A project without a published release must not be labeled Stable solely because its source is public.

Review navigation, cards, keyboard focus and overflow at desktop, tablet and phone widths when changing layout.
