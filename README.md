# Regstar GitHub Pages

Personal GitHub Pages site for [Regstar2](https://github.com/Regstar2).

## Site

https://regstar2.github.io/

## Structure

- `index.html` — page content and project cards.
- `styles.css` — responsive layout, typography and theme.
- `script.js` — skeleton easter egg dialog.
- `app-ads.txt` — existing advertising declaration used by published apps.

The site is intentionally static and does not require a build step.
