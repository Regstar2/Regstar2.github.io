Политика конфиденциальности приложения PDF Мастерская

Дата актуализации: 26 ноября 2026 г. Приложение: PDF Мастерская / PDF Workbench (regstar2.pdfworkbench). Разработчик адаптации: Regstar2. Политика описывает конфигурацию, подготовленную для выпуска в RuStore.

Обработка документов

Приложение обрабатывает выбранные пользователем документы, изображения и результаты распознавания текста на устройстве. Для просмотра, редактирования и сохранения используются выбранные пользователем файлы и папки. Приложение может сохранять историю операций, настройки, временные и выходные файлы. Доступ к камере запрашивается при использовании сканирования. На поддерживаемых версиях Android используются системный выбор файлов и разрешения хранилища.

Реклама

В варианте для RuStore предусмотрена реклама через Yandex Mobile Ads SDK. SDK может передавать Яндексу технические сведения, необходимые для получения и измерения объявлений, в том числе сведения о приложении и устройстве и сетевом соединении. Содержимое документов не передаётся рекламному SDK приложением. Приложение не запрашивает доступ к местоположению для рекламы и не передаёт SDK согласие на обработку персональных данных, которого пользователь не предоставил. В подготовленной конфигурации удалено разрешение AD_ID. В составе SDK могут использоваться AppMetrica, идентификаторы приложения и набора приложений, IP-адрес и сведения о взаимодействии с рекламой для работы рекламной системы. Дополнительные сведения о правилах обработки данных Яндексом: Политика конфиденциальности Яндекса, документация SDK.

Хранение и управление данными

Файлы, сохранённые в выбранных папках, доступны для удаления средствами Android. В зависимости от настроек Android данные приложения могут участвовать в системном резервном копировании. Локальные настройки и история могут быть удалены при очистке данных приложения; удаление приложения не обязательно удаляет файлы, которые пользователь сохранил в общих папках. Содержимое документов может передаваться другим приложениям только через выбранные пользователем функции открытия или обмена. Рекламные настройки и идентификаторы могут регулироваться средствами Android и применимыми настройками сервисов Яндекса.
