> android / markdown reminders

NotifyMark

Local reminders for tasks that remain in your Markdown files.

The app reads built-in or Android SAF-selected Markdown storage, shows tasks in a list and calendar, schedules local notifications, and writes completion, skip, or edit changes back to the source line.

Markdown stays the source of truth.

NotifyMark does not turn notes into a second independent task database. Current task state stays in Markdown, while local data supports scheduling, preferences, and recurrence history.

Connect existing notes

Use built-in app storage, a single Markdown file, or a folder selected through Android Storage Access Framework.

Schedule reminders locally

Android alarms and notifications are scheduled on-device. Exact timing may require exact-alarm special access depending on the Android version.

What is already in the beta.

The features below reflect the published v0.10.1-beta.1 release and current project documentation.

01

List and calendar

Review tasks in a regular list and calendar view.

02

Recurrence and snooze

Supports recurrence, repeat-until-done, grace periods, and snoozed reminders.

03

Notification actions

Complete, snooze, skip, or open a task directly from the notification.

04

Groups, tags, priorities

The native format supports groups, tags, priorities, and subtasks.

05

Markdown write-back

Completion, skip, and edit actions update the source line in the selected Markdown document.

06

Obsidian Tasks

Partial compatibility with Obsidian Tasks emoji metadata. Query blocks, query language, and the full recurrence grammar are not supported.

The format remains readable Markdown.

NotifyMark native metadata lives directly on the task line and can be edited with a normal text editor.

> privacy

No app-owned network client

According to the current manifest/security audit, the app does not request INTERNET and does not perform its own HTTP/socket requests. External files are accessible only after the user selects them through SAF.

  • Tasks and settings are processed locally
  • External access is limited to user-selected SAF sources
  • App-owned data is excluded from Android cloud backup/device transfer
