> android / markdown reminders

NotifyMark

Локальные напоминания по задачам, которые остаются в ваших Markdown-файлах.

Приложение читает встроенное или выбранное через Android SAF Markdown-хранилище, показывает задачи списком и в календаре, планирует локальные уведомления и записывает выполнение, пропуск или редактирование обратно в исходную строку.

Markdown остаётся источником истины.

NotifyMark не превращает заметки во вторую независимую базу задач. Текущее состояние задачи хранится в Markdown, а локальные данные используются для расписания, настроек и истории повторений.

Подключите существующие заметки

Можно использовать встроенное хранилище приложения, отдельный Markdown-файл или папку через Android Storage Access Framework.

Получайте напоминания локально

Android alarms и уведомления создаются на устройстве. Для точного времени может потребоваться отдельный доступ exact alarms в зависимости от версии Android.

Что уже есть в beta.

Функции ниже взяты из опубликованного v0.10.1-beta.1 и текущей документации проекта.

01

Список и календарь

Просмотр задач в обычном списке и календарном представлении.

02

Повторения и snooze

Поддерживаются повторения, repeat-until-done, grace period и отложенные напоминания.

03

Действия из уведомления

Задачу можно выполнить, отложить, пропустить или открыть прямо из уведомления.

04

Группы, теги и приоритеты

Нативный формат поддерживает группы, теги, приоритеты и подзадачи.

05

Запись обратно в Markdown

Выполнение, пропуск и редактирование обновляют исходную строку выбранного Markdown-документа.

06

Obsidian Tasks

Есть частичная совместимость с emoji metadata Obsidian Tasks. Query blocks, query language и полная грамматика recurrence не поддерживаются.

Формат остаётся читаемым Markdown.

Нативные метаданные NotifyMark находятся прямо в строке задачи и могут редактироваться обычным текстовым редактором.

- [ ] Подготовить отчёт @due(2026-10-05 18:00) @priority(high) #учёба
- [ ] Проверить резервную копию @repeat(1w) @snooze(30m)

@due(...)  @repeat(...)  @repeatUntilDone(...)
@grace(...)  @group(...)  @priority(...)  @tag(...)

> приватность

Без собственного сетевого клиента

По текущему manifest/security audit приложение не запрашивает INTERNET и не выполняет собственные HTTP/socket-запросы. Внешние файлы становятся доступны только после выбора через SAF.

  • Задачи и настройки обрабатываются локально
  • Внешний доступ ограничен выбранными SAF-источниками
  • Внутренние данные исключены из Android cloud backup/device transfer
