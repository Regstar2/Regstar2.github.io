> android.network_diagnostics

WhiteList
Checker

Диагностика мобильной сети и обнаружение признаков режима белых списков.

Проверяет доступность ресурсов именно через cellular-сеть, сопоставляет HTTPS и DNS-сигналы, сохраняет историю и помогает увидеть изменение состояния сети во времени.

$ overview

Что делает приложение

Не пытается «узнать правила оператора». Вместо этого измеряет наблюдаемое поведение мобильной сети и показывает, на каком уровне возникает проблема.

01
CELL

Проверка через мобильную сеть

Получает отдельный cellular Network через Android ConnectivityManager. Wi-Fi при этом можно оставить включённым.

02
DNS

DNS-диагностика

UDP/53, TCP fallback, пользовательские resolver и системный cellular resolver.

03
TLS

HTTPS targets

Проверяет группы LOCAL и FOREIGN через network-bound сокеты с обычной TLS-проверкой.

04
MON

Мониторинг

Фоновые проверки через WorkManager и активный мониторинг через foreground service.

05
LOG

История и статистика

Room-хранилище, timeline и экспорт накопленных данных в CSV, JSON или TXT.

06
NTF

Уведомления

Локальные Android-уведомления и опциональная личная Telegram-интеграция.

> signal_pipeline

Как формируется результат

01 Cellular Network Android network binding
→
02A HTTPS LOCAL / FOREIGN
02B DNS Resolver diagnostics
→
03 Classification Наблюдаемое состояние

! Результат — диагностическая оценка по наблюдаемым сетевым признакам, а не доказательство наличия у оператора конкретного режима фильтрации.
