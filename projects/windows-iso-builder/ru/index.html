GUI намеренно остаётся тонким слоем: UUP-каталог, рекомендации, BuildPlan, preflight, повышение прав, загрузка/конвертация, DISM, проверка ISO и отмена остаются в PowerShell-бэкенде и доступны через версионируемый машинный контракт.

> контекст

От каталога UUP до ISO без ручной работы с SKU и UUID

Проект превращает UUP dump workflow в воспроизводимый desktop-сценарий, сохраняя PowerShell backend для CLI и автоматизации.

01 / проблема

Сырой UUP workflow раскрывает слишком много деталей

Ручной выбор сборок, UUID, языка, редакций, converter settings, сетевой политики и проверки результата усложняет повторяемость и увеличивает риск ошибки.

02 / подход

Интерфейс поверх одного авторитетного backend

Quick Mode и Catalog Mode сходятся в общий backend-owned путь языка, редакций, BuildPlan, preflight и сборки. GUI не дублирует UUP/DISM-логику.

> возможности

Основные возможности

Стабильный релиз объединяет GUI, CLI, сеть, прокси, диагностику и проверяемую сборку ISO.

01CAT

Динамический UUP-каталог

Windows 10/11 обнаруживаются через UUP dump без захардкоженного build-каталога.

02ED

Языки и редакции

Динамические языки/редакции, multi-edition и выбор WIM/ESD.

03CHK

Структурированный preflight

Проверки выполняются до привилегированного этапа, чтобы проблемы показывались до UAC.

04BUILD

Жизненный цикл сборки

Backend управляет elevation, progress, cancellation, логами, ISO validation и SHA-256.

05NET

Network Policy

System / Direct / Custom действует для UUP API, preflight, downloads, aria2 и update checks.

06PROXY

HTTP и SOCKS5

Custom HTTP/SOCKS5 работает fail-closed; generated downloader использует loopback bridge.

07UI

GUI + CLI

WPF, Start-Builder.cmd, Start-Builder.ps1 и JSON/NDJSON backend entry point.

08I18N

RU / EN

Русский и английский интерфейс, English fallback, System / Light / Dark.

09UPD

Проверка обновлений

Официальный GitHub Releases без автоматического скачивания или запуска обновления.

> интерфейс

Скриншоты приложения

Реальные скриншоты v1.0.0 из репозитория, без обрезки.

$ архитектура

Архитектура

GUI остаётся тонким клиентом поверх машинного контракта.

WPF / MVVM

Тонкий C# .NET 10 client. MainViewModel управляет UI flow, transport остаётся в Backend/.

BackendClient

Создаёт собственные transport-каталоги, сериализует JSON, запускает публичный PowerShell entry point и проверяет schema compatibility.

Backend Contract v1

Стабильные команды версии, каталога, рекомендаций, языков, редакций, BuildPlan, preflight, запуска и cancellation.

PowerShell module

Единственный владелец UUP discovery, BuildPlan, preflight, elevation, download/conversion/DISM, ISO validation и cancellation.

Telemetry

NDJSON progress — телеметрия; финальный backend response остаётся авторитетным.

UAC boundary

GUI работает asInvoker; elevation принадлежит backend, а отмена возвращается структурированным результатом.

> инженерные решения

Инженерные решения

Проект предпочитает явные границы, воспроизводимость и fail-closed поведение.

Архитектура

Не создавать второй build engine

GUI не реализует заново UUP, DISM, recommendation, preflight или cancellation.

Прокси

Custom работает fail-closed

Ошибка config или connection не превращается в скрытый Direct retry.

Credentials

DPAPI CurrentUser

Сохранённые proxy passwords защищены и не записываются в settings, BuildPlan, logs и artifacts.

Downloader

Loopback bridge

Generated aria2 видит 127.0.0.1 вместо upstream proxy credentials в command line.

Обновления

Discovery, а не self-update

Используется официальный GitHub Releases и проверенная release page.

Валидация

Реальный ISO важнее unit-test

v1.0.0 включает исправления после реального Windows 11 E2E, включая проверку ESD/WIM.

> безопасность

ЯВНЫЕ ГРАНИЦЫ

Привилегированные операции и секреты имеют явные границы.

Приложение не отключает UAC/антивирус, не содержит GitHub PAT/OAuth token и не выполняет произвольные PowerShell-имена, переданные через JSON.

  • Явный allowlist backend-команд
  • Нет Invoke-Expression/eval dispatch
  • GUI запускает процессы через ArgumentList
  • Proxy password защищён DPAPI CurrentUser
  • Diagnostics используют allowlist и sanitization
  • Diagnostic ZIP всё равно нужно просмотреть перед публикацией
Важно: Windows ISO Builder собирает установочные образы через UUP dump и инфраструктуру Microsoft. Windows, UUP dump и сторонние инструменты сохраняют собственные лицензии и условия.
